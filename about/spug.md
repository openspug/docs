`Spug` 是面向中小型企业设计的轻量级、无 Agent 的自动化运维平台，通过 SSH 协议管理主机，无需在被管主机上安装任何客户端。
平台整合了主机管理、批量执行、在线终端、文件管理与分发、应用发布、流水线、任务计划、配置中心、监控报警、凭据与权限管理等一系列功能。

:::tip 在线体验
演示环境：[https://demo.spug.cc](https://demo.spug.cc)（账户 `admin` / 密码 `spug.cc`）。演示环境运行最新版本，数据每小时自动重置，可在页面右上角的地球图标处切换简体中文 / English 界面。
:::

## 特性

- **主机管理**：主机分组管理，支持从阿里云、腾讯云或 Excel 批量导入，批量验证连通性并同步主机配置信息
- **批量执行**：多主机在线批量执行 Shell / Python 命令，支持参数化命令模板与执行历史
- **在线终端**：浏览器内直接登录主机终端，多标签、多主题，支持独立的文件管理器
- **文件管理**：主机文件在线上传、下载、删除
- **文件分发**：把本地上传的文件或某台主机上的目录一次分发到多台主机
- **应用发布**：常规发布与自定义发布两种模式，支持发布审核、构建与发布分离、定时发布、灰度 / 补偿发布、回滚以及 Webhook 自动发布
- **流水线**：以节点编排的方式组合参数化、构建、执行命令、数据传输、数据上传、钉钉 / 飞书 / 企业微信 / 推送助手通知等模块，支持条件分支与实时控制台
- **任务计划**：支持一次性、Cron、固定间隔以及监控告警触发的任务，可在多台主机或本机执行
- **配置中心**：按环境维护应用与服务配置，支持 KV、文本、JSON 三种视图，提供开放 API 供应用读取
- **监控中心**：站点、端口、Ping、进程与自定义脚本五种检测方式，告警可联动任务计划自动处理
- **报警中心**：支持微信、邮件、钉钉、企业微信、飞书等报警渠道
- **凭据管理**：集中管理密码与密钥，供构建仓库等场景复用
- **权限控制**：细粒度的功能、主机、发布权限，支持 LDAP 登录与登录 MFA 两步验证
- **中英双语**：界面支持简体中文与 English，可随时切换
- **优雅美观**：基于 Ant Design 的 UI 界面
- **开源免费**：前后端代码完全开源（AGPL-3.0）

## 环境要求

| 组件 | 版本 |
| --- | --- |
| Python | 3.8 及以上 |
| Django | 4.2 |
| Node.js | 18 及以上（仅二次开发前端时需要，推荐 20 LTS） |
| Redis | 5.0 及以上 |
| 数据库 | MySQL 8.0.11 及以上 / MariaDB 10.4 及以上（Docker 安装内置 MariaDB 10.8），二次开发可使用 SQLite 3.21 及以上 |
