### 一、说明

通过[渠成软件百宝箱](https://www.qucheng.com/) 使用一条命令即可安装 Spug，操作简单易上手。渠成软件百宝箱提供了企业级应用市场及服务管理，代码开源、安全可控。

通过命令行工具安装 Spug 时，会先安装渠成软件百宝箱，然后再安装 Spug。

### 二、硬件与系统要求

| 类型   | 说明                                                                     |
| ---- | ---------------------------------------------------------------------- |
| 硬件要求 | 2核CPU，4G内存，40G硬盘，虚拟机/云主机/物理机均可                                         |
| 系统要求 | Debian Bullseye 、Buster - 推荐 <br />Ubuntu 22.04、20.04 <br />CentOS 7.x |

### 三、在线体验

- [在线安装Spug](https://www.qucheng.com/market-view-76.html) 

### 四、渠成命令行安装 Spug


:::caution 注意
通过以下命令行工具安装 Spug 时，会先安装渠成软件百宝箱，然后再安装 Spug，默认安装当前发行的最新版。
:::

`curl -sSL https://pkg.qucheng.com/qucheng/cli/stable/install.sh |INSTALL_APP=spug sh - `
