以下整理社区中反馈的常见问题和官方答复，在提问之前建议先找找有没有类似的问题。

### 安装运行常见问题
请参考 [安装相关问题](/docs/install-problem) 与 [使用常见问题](/docs/use-problem) 文档。

### `Spug` 还可以支持更多新特性 / 功能吗？
可以，我们也在不断完善开发新的功能，如果你有想法可以关注公众号留言或在 [GitHub Issues](https://github.com/openspug/spug/issues) 提交。

### 验证主机时我输入的密码安全吗？
安全，你输入的密码仅用于当次建立密钥登录使用，并不会存储在任何地方或用于他处。之后 `Spug` 均通过密钥登录主机，详见 [主机管理](/docs/host-manage#principle)。

### 我不需要监控中心的功能，可以不启动 runmonitor 服务吗？
可以，包括任务计划模块，如果你不需要这个功能，也不必启动 runscheduler 服务。但批量执行、发布、流水线等功能依赖 runworker 服务，请保持其运行。

### 我必须要关注公众号才可以使用内置的报警服务吗？
是的，我们为不便二次开发的用户提供了内置的微信 / 邮件报警服务，为了防止服务被恶意使用，需要在 `系统管理 / 系统设置 / 基本设置 / 调用凭据` 中配置调用凭据，同时每个报警联系人需要填写各自的[微信 Token](/docs/wx-token)。钉钉、企业微信、飞书等群机器人渠道以及自定义邮件服务不依赖调用凭证。

### 内置的报警服务为什么不开源直接放在项目内呢？
因为不管是微信 / 邮件 / 短信都需要配置一些敏感信息才可以使用，例如微信的 `APP_ID`、邮件服务的账户密码等，所以暂无法开源。
另外我们也在系统设置的报警服务设置中提供了自定义邮件服务的相关配置，以便你使用自己的邮件服务。

### 短信、电话告警怎么接入？
`Spug` 集成了 [推送助手](https://push.spug.cc)，在 `系统管理 / 系统设置 / 推送服务设置` 中绑定推送助手账户后，流水线可以直接使用推送助手节点发送短信、电话、邮件、微信公众号消息；监控告警的短信 / 电话推送请参考 [推送助手接入文档](https://push.spug.cc/guide/spug)。

### 界面可以切换成英文吗？
可以，4.0 版本开始界面支持简体中文与 English，点击页面右上角的地球图标即可切换，设置保存在浏览器本地。
