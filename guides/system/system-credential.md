## 介绍

`凭据管理` 是 4.0 新增的模块，用于集中保存访问外部系统所需的账户密码或私钥，目前主要供 [流水线](/docs/pipeline-modules#构建) 的构建节点访问私有 Git 仓库使用，避免把密码明文写在脚本或仓库地址中。

![凭据管理](/img/docs/4.0/zh/credential-form.jpg)

## 配置项

- **凭证类型**：
  - `密码`：用户名 + 密码（或 Access Token），用于 `http/https` 协议的仓库地址；
  - `密钥`：用户名 + 私钥内容（可选私钥密码），用于 `ssh` 协议的仓库地址，请把对应的公钥添加到代码托管平台。
- **凭证名称**：便于识别的名称。
- **用户名**：仓库的登录用户名，密钥类型一般为 `git`。
- **密码 / 私钥 / 私钥密码**：根据类型填写。
- **共享凭据**：默认凭据仅创建者自己可以使用，开启后其他用户也可以在流水线中选择该凭据，但无法查看密钥内容。

## 使用

在流水线构建节点的 **访问凭据** 下拉框中选择凭据，输入 Git 仓库地址后 `Spug` 会使用该凭据自动检测仓库是否可访问。

## 权限说明

凭据管理页面位于系统管理菜单下，仅管理员可见；共享出来的凭据其他用户可以在流水线中选择使用，但看不到密钥内容也不能修改，只有创建者本人可以编辑或删除。
