## 介绍

记录平台所有账户的登录行为，包含登录时间、账户名称、登录方式（普通登录 / LDAP 登录）、登录结果、登录 IP、User Agent 以及失败时的提示信息，可用于安全审计与异常登录排查。

![登录日志](/img/docs/4.0/zh/login-log.jpg)

## 使用说明

- 支持按 **账户名称** 与 **登录 IP** 过滤。
- 登录失败的记录会显示失败原因（如密码错误、账户被禁用、验证码错误）。
- 连续登录失败超过 3 次后账户会被自动禁用，普通账户可在 [账户管理](/docs/system-account) 中重新启用，管理员账户需要通过命令行启用。
- 登录日志保留最近 30 天，超期自动清理。
