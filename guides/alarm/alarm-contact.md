## 介绍

维护报警的联系人相关内容，每种额外信息对应一种报警方式，监控中心的报警方式会根据联系人配置的信息发送到对应的渠道。

![报警联系人](/img/docs/4.0/zh/alarm-contact-form.jpg)

## 配置项

| 配置项 | 对应报警方式 | 说明 |
| --- | --- | --- |
| 姓名 | - | 联系人名称 |
| 手机号 | 短信 | 预留字段，短信 / 电话告警请通过 [推送助手](https://push.spug.cc/guide/spug) 接入 |
| 邮箱 | 邮件 | 使用内置邮件服务（需要调用凭据）或 `系统设置 / 报警服务设置` 中配置的自定义邮件服务发送 |
| 微信Token | 微信 | 关注公众号 <font color="#1890ff">Spug</font> 在 **我的** 菜单中获取，详见 [微信 Token](/docs/wx-token) |
| 钉钉 | 钉钉 | 钉钉群机器人的 Webhook 地址 |
| 钉钉 Secret | 钉钉 | 机器人安全设置选择 `加签` 时填写，未开启加签可留空 |
| 企业微信 | 企业微信 | 企业微信群机器人的 Webhook 地址 |
| 飞书 | 飞书 | 飞书群机器人的 Webhook 地址 |
| 飞书 Secret | 飞书 | 机器人安全设置选择 `签名校验` 时填写，未开启可留空 |

列表中的 **执行测试** 可以向该联系人配置的各渠道发送一条测试消息，用于验证配置是否正确。

## 小提示

- 内置的微信和邮件报警模式需要配置调用凭据，调用凭据的获取方式与微信 Token 相同，获取调用凭据后，将调用凭据配置至 `系统设置 / 基本设置` 中的调用凭据中即可。
- 调用凭据可以是任何一个有效的微信 Token。
- 由于微信的限制，你必须关注公众号才能收到微信报警信息。
