## 介绍

用于维护应用的配置，应用配置包含 `公共` 和 `私有` 两种类型的配置。

![应用配置](/img/docs/4.0/zh/config.jpg)

- `公共` 配置

  该类型的配置可以被其他应用所使用。比较典型的例子：应用 B 需要调用应用 A 的某接口，那么应用 B 必然需要知道应用 A 的 IP 或域名，这时就可以在应用 A 上添加个
   `公共` 类型的配置以供应用B来使用。为什么不把这个配置放在应用 B 里呢？因为如果还有应用 C / D / E / F 也要调用A呢？在 C / D / E / F 中都配
   置一遍即麻烦又难以维护。

- `私有` 配置

  仅用于此应用的配置，并不会被其他应用所获取到。

## 配置项

- **应用名称 / 标识符 / 备注信息**：与 [应用发布 / 应用管理](/docs/deploy-app) 中的应用是同一份数据，标识符会作为生成配置的前缀。

## 依赖

点击应用行的 **依赖** 可以设置该应用依赖的其他应用与服务，设置后该应用（通过 API 或发布时的环境变量）能够获取到所依赖应用的 `公共` 配置以及所依赖服务的全部配置。

![配置依赖](/img/docs/4.0/zh/config-app-rel.jpg)

## 小提示

- `公共` 和 `私有` 类型的配置都会被应用自身获取到，它们的区别仅仅是当其他应用依赖该应用时，`公共` 配置会提供给依赖应用而 `私有` 配置不会。
- 配置中心用于解决不同环境间配置的差异，如果各个环境下某配置的值都是相同的，就可以直接在代码中硬编码而不需要把这些配置放到配置中心维护。
- 点击 **配置** 进入该应用的配置管理页面，用法见 [配置管理](/docs/conf-set)。
