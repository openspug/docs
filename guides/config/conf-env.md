## 介绍

管理应用的运行环境，一般包含开发环境、测试环境和生产环境，应用发布和配置管理需要用它来区分不同的环境。

![环境管理](/img/docs/4.0/zh/config-env.jpg)

## 配置项

- **环境名称**：例如 `测试环境`、`生产环境`。
- **标识符**：环境的唯一标识符，由字母、数字和下划线组成，用于配置中心提供的开放 API 调用（`env` 参数）以及发布脚本中的 `$SPUG_ENV_KEY` 变量，详情参考 [API 文档](/docs/config-api)。
- **备注信息**：可选。

## 小提示

- 环境被发布配置或配置项引用后无法直接删除，请先清理相关引用。
- 角色的 [发布权限](/docs/system-role#deploy-perm) 按环境授权，可以限制普通用户只能发布到测试环境。
