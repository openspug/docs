## 介绍

维护服务和应用在不同环境下的具体配置，从服务管理或应用管理页面点击 **配置** 进入。页面左侧为环境列表，右侧为当前环境下的配置。

![配置管理](/img/docs/4.0/zh/config-setting.jpg)

:::tip 提示
在 Spug 之外使用配置中心的配置信息，请参考 [API 文档](/docs/config-api)。
:::

## 三种视图

- **表格视图**：逐条新建、编辑、删除配置，每条配置包含 `Key`、`Value`、`备注`；新建时可以勾选 **选择环境** 一次性复制到多个环境。
- **文本视图**：以 `key = value` 的文本形式批量编辑，`#` 或 `;` 开头的行为注释，适合一次性录入大量配置。
- **JSON 视图**：以 JSON 对象的形式批量编辑。

## 对比配置

点击 **对比配置** 可以选择多个环境，逐项比较配置在各环境中的差异，快速发现遗漏或不一致的配置。

![对比配置](/img/docs/4.0/zh/config-diff.jpg)

## 更改历史

点击右上角的 **更改历史** 可以查看该环境下所有配置的新增、修改、删除记录，包含修改前后的值、操作人与时间；通过发布脚本中的 `SPUG_SET` 动态更新的配置也会记录在内。

## 小提示

- 当需要一次性录入大量配置时可以使用 `文本模式` 或 `JSON模式`。
- `Key` 只能由字母、数字和下划线组成，最终对外暴露时会加上 `标识符_` 前缀防止不同应用 / 服务的配置冲突。
- 查看与修改配置分别对应 `查看配置` 与 `修改配置` 两个功能权限。
