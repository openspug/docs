## 介绍

`Web 终端` 让你无需本地 SSH 客户端即可在浏览器中登录主机，同时提供文件管理器用于上传、下载主机文件。入口有两处：

- 主机管理页面右上角的 **Web 终端** 按钮；
- 页面顶部导航栏的终端图标，会在新窗口打开。

![Web 终端](/img/docs/4.0/zh/web-terminal.jpg)

## 终端操作

- 左侧为主机列表（与主机管理的分组一致），支持按主机名 / IP 检索，点击主机即可打开一个终端标签，同一主机可以同时打开多个连接。
- **双击标签** 快速复制一个同主机的新窗口，**右键点击标签** 可以复制窗口、重新连接、关闭右侧 / 其他 / 所有标签。
- 终端支持 `PageUp` / `PageDown` 翻页、`Ctrl + C` 复制选中的内容，终端区域宽度可以拖拽调整。
- 点击右上角的 **终端设置** 可以自定义字体大小、字体名称以及主题配色，设置保存在浏览器本地。

:::tip 提示
- 终端会话通过 WebSocket 建立，如果打开后一直无输出，请参考 [使用常见问题](/docs/use-problem#websocket) 检查反向代理配置。
- 离开页面时会提示确认，避免误关闭正在使用的会话。
:::

## 文件管理器

在终端标签页内点击 **文件管理器** 即可查看当前主机的文件系统，也可以在主机列表中直接以独立的文件管理器模式打开（仅查看文件，不需要终端权限）。

![文件管理器](/img/docs/4.0/zh/file-manager.jpg)

- 支持进入目录、返回上级、直接输入路径回车跳转，最近访问过的路径会被记录方便快速切换。
- 可以按名称、大小、修改时间排序，开关 **显示隐藏文件**。
- **上传文件**：选择本地文件上传到当前目录，上传过程中会展示进度条。
- **下载**：点击文件的下载按钮即可下载到本地。
- **删除**：删除主机上的文件（需要单独的删除权限）。

## 权限说明

Web 终端相关的功能权限在 `系统管理 / 角色管理 / 功能权限` 的 **主机管理 / Web终端** 分组下，分别为：

| 权限 | 说明 |
| --- | --- |
| Web终端 | 允许打开终端登录主机 |
| 文件管理 | 允许查看文件列表、下载文件 |
| 上传文件 | 允许上传文件到主机 |
| 删除文件 | 允许删除主机上的文件 |

可见的主机范围由角色的 [主机权限](/docs/system-role#host-perm) 决定。
